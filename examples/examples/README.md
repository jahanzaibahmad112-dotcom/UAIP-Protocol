# 📝 UAIP Examples

Working code examples for common use cases.

## Getting Started

### 1️⃣ Hello World (Simplest)
```bash
python 01_hello_world.py
```
Creates an agent and registers with gateway.

### 2️⃣ Agent-to-Agent Payment
```bash
python 02_agent_to_agent.py
```
Two agents transacting with each other.

### 3️⃣ LangChain Integration
```bash
export OPENAI_API_KEY="your-key"
python 03_langchain_integration.py
```
Payment-enabled LangChain agent.

### 4️⃣ AutoGen Multi-Agent
```bash
export OPENAI_API_KEY="your-key"
python 04_autogen_integration.py
```
Multi-agent approval workflow.

### 5️⃣ CrewAI Team
```bash
export OPENAI_API_KEY="your-key"
python 05_crewai_integration.py
```
Procurement automation crew.
